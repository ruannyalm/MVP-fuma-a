# Livros da Ruanny

Uma página simples para apresentar e vender livros.

## Sobre o projeto

Este projeto foi feito com HTML, CSS e JavaScript. A página mostra alguns livros, seus preços e um formulário para fazer pedidos.

## Arquivos

- `index.html`: cria a estrutura da página.
- `style.css`: define as cores, os tamanhos e o visual.
- `script.js`: adiciona as ações dos botões e do formulário.

## Recursos

- Apresentação da livraria.
- Lista com três livros.
- Imagens dos livros usando links da internet.
- Botão para mostrar uma mensagem de compra.
- Formulário com nome, livro e quantidade.
- Mensagem de confirmação depois do pedido.
- Layout adaptado para celular.

## Como abrir

1. Baixe ou clone este projeto.
2. Abra a pasta no computador.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nada para visualizar a página.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
